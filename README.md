# My Suckless Setup 

This is my personal dwm, st, dmenue configuration. The status bar uses my own custome bash script.


## Components

- dwm - Tiling window manager
- st - Simple terminal
- dmenu - Application launcher
- status-bar.sh - Custom Bash status bar

## Dependecies

Scrot - for screenshots. It will build without it, but the keybinds for screenshot won't work.
